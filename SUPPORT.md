# Support

- **Ideas**: open an issue with the **Feature request** template.
- **Questions**: open an issue with the **Question** template and describe
  what you are trying to do.
- **Bugs**: open a bug report with your OS, the app version (Settings → About),
  the agent CLI and its version, and the steps to reproduce.
- **Security problems**: never in a public issue, see [SECURITY.md](SECURITY.md).
- **PromptOps Desktop (hosted edition)**: write to info@shellonback.com.
