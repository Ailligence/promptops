<h1 align="center">PromptOps</h1>

<p align="center">
  <strong>The control room for your coding agents.</strong><br/>
  Run Claude Code, Codex, Gemini CLI and every other CLI agent side by side, organized by client and project, on your machine.
</p>

## Install and open

```bash
npx @shellonback/promptops
```

This installs **PromptOps Desktop** at the version of this package, from [GitHub Releases](https://github.com/shellonback/promptops/releases). Before anything is installed, the download must carry a valid signature from the PromptOps release key; anything else is deleted.

- **macOS**: installs it in `~/Applications` and opens it. If PromptOps Desktop is already installed at this version or newer, it just opens it.
- **Windows**: opens the installer.
- **Linux**: runs the AppImage from the download cache.

Options: `--download-only` (download and verify, print the path), `--install-only` (install without opening).

Nothing is sent anywhere except the downloads from GitHub.

## Open source

The open-source edition, with no account and no server, is at [github.com/shellonback/promptops](https://github.com/shellonback/promptops): read it, build it, change it.
