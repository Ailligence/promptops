# Dependencies and known advisories

How the dependencies of PromptOps are pinned and checked, and the published
advisories that still match a dependency, with the reason each one does not
affect the app. Updated on 2026-10-22.

## How dependencies are pinned

- **Rust**: `apps/desktop/src-tauri/Cargo.lock` (lockfile format 3, readable
  by every Cargo from 1.53 on). CI builds with it as committed.
- **npm**: `apps/web/package-lock.json` and `apps/desktop/package-lock.json`
  (lockfile format 3), installed with `npm ci`. `apps/npm` has no
  dependencies, so it has no lockfile.
- **GitHub Actions**: every action is pinned to a full commit SHA, with the
  release tag in a comment. Dependabot proposes updates weekly
  (`.github/dependabot.yml`).
- **Overrides** (`overrides` in `package.json`) replace vulnerable transitive
  versions that the direct dependency has not updated yet:

  | Package | Forced to | Why |
  |---|---|---|
  | `dompurify` (web, under monaco-editor) | `^3.4.17` | keeps the sanitizer on a current 3.x release |
  | `vite` (web, dev server and build) | `8.3.5` | Angular 22.2 pins 8.3.0, affected by GHSA-9jrq-w75r-8gcw, GHSA-rq7h-c2jc-7f22, GHSA-vfpm-58rq-9qcg and the launch-editor advisories |
  | `protobufjs` (desktop, under `@xenova/transformers`) | `^7.6.3` | GHSA-66ff-xgx4-vchm (critical) and related advisories in 6.x |
  | `sharp` (desktop, under `@xenova/transformers`) | `^0.35.5` | libvips, libheif and librsvg advisories in 0.32 |

  The desktop overrides were checked by embedding real text with the
  sidecar (`src-tauri/resources/embeddings-sidecar.js`): the vectors are
  identical to the ones produced with the original versions.

## How to check

```bash
(cd apps/web && npm audit --omit=dev && npm audit)
(cd apps/desktop && npm audit)
(cd apps/desktop/src-tauri && cargo audit)   # cargo install cargo-audit --locked
```

An SBOM can be produced locally with
`npx @cyclonedx/cyclonedx-npm --omit dev` (in `apps/web`) and
`cargo cyclonedx --target all` (in `apps/desktop/src-tauri`, after
`cargo install cargo-cyclonedx --locked`). The third-party notices shipped
with the app are generated by `node scripts/generate-notices.mjs`, which the
web build runs on every build.

## Open advisories

None of these has a fixed version that the dependency tree can use today.

| Advisory | Where | Why it does not affect PromptOps |
|---|---|---|
| RUSTSEC-2023-0071 (`rsa`, Marvin timing attack) | `rsa` 0.9 under `sqlx-mysql`; `rsa` 0.10-rc under `russh` | The attack needs an attacker who can time many RSA decryptions or signatures made with a private key. The MySQL driver only *encrypts* the password with the server's public key. The SSH client signs once per login with your key, on your machine. No fixed `rsa` release exists. |
| RUSTSEC-2024-0429 (`glib` 0.18, unsound `VariantStrIter`) | Linux only, under GTK/WebKitGTK (Tauri 2 uses gtk-rs 0.18) | PromptOps never calls `VariantStrIter`. The fix is in glib 0.20, which Tauri 2's GTK stack does not use yet. |
| Unmaintained crates: `paste`, `proc-macro-error`, `serial`, `unic-*`, `zbus_names`/`zvariant`/`zvariant_derive` | build-time macros and Tauri/keyring internals | Informational only (no vulnerability). They come with Tauri, `keyring` and `portable-pty` and leave when those crates move on. |
| GHSA-vfj7-8cjw-p6xm (`braces` ≤ 3.0.3, stack exhaustion) | web **dev** dependencies only (Karma, the Angular dev server proxy) | Not shipped in the app. It needs an attacker-controlled glob pattern; the dev tools only receive patterns from this repository. No fixed version exists. |
